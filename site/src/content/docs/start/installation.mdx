Zero runtime dependencies. Requires Node 20 or later; also runs in Bun, Deno and modern browsers.

## Import

<Tabs syncKey="module">
  <TabItem label="ESM / TypeScript">
    ```ts

    ```
  </TabItem>
  <TabItem label="CommonJS">
    ```js
    const { EnhancedAbortController, TimeSpan } = require('@ylcnfrht/enhanced-abort-controller');
    ```
  </TabItem>
</Tabs>

The package ships separate ESM and CommonJS builds with their own type declarations. A `TimeSpan` created by one build is accepted by the other (delays are checked by shape, not by `instanceof`).

## TypeScript

Types are included. Two settings matter:

- **`using` declarations** need TypeScript 5.2 or later. TypeScript compiles them down for runtimes that don't support them natively; Node 24 and Chrome 134 run them as is. Without `using`, call `controller.dispose()` in a `finally`.
- **The `Disposable` type.** In Node projects `@types/node` provides it. Browser-only projects without `@types/node` need the disposable lib:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "ESNext.Disposable", "DOM"]
  }
}
```
